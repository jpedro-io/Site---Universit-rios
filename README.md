# 🚍 Transporte Universitário - Divisa Alegre (MG)

Site oficial da Comissão de Transporte dos Universitários de Divisa Alegre (MG) para Vitória da Conquista (BA). Um portal leve, rápido e desenvolvido para facilitar o acesso dos estudantes às informações essenciais do transporte.

## 🚀 Funcionalidades

* **Previsão do Tempo:** Consulta em tempo real (via Open-Meteo) das condições meteorológicas em Vitória da Conquista.
* **Regras e Critérios:** Informações detalhadas sobre a ordem de prioridade da lista e horários de saída.
* **Guia de Universidades:** Endereços e detalhes das instituições atendidas.
* **Manual dos Universitários:** Ferramentas de produtividade, plataformas de estudo com certificado e declarações úteis.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído priorizando a performance e a simplicidade, **sem dependências externas pesadas**:
* **Frontend:** HTML5, CSS3 moderno e JavaScript puro (Vanilla JS).
* **Backend:** Node.js puro (`node:http`), sem a necessidade de frameworks complexos como Express.
* **APIs Externas:** Open-Meteo (para dados climáticos gratuitos e sem chave).
* **Hospedagem:** Vercel.
